# Interactive Card Details Form

A responsive and interactive card details form built with **React, TypeScript, and Tailwind CSS**.

This project is a solution to the **Frontend Mentor Interactive Card Details Form** challenge. Users can enter their card details and see the information update on the card preview in real time.

## Features

* Responsive layout for mobile and desktop
* Real-time card preview
* Cardholder name updates instantly
* Card number formatting
* Expiration date preview
* CVC preview
* Form validation
* Error messages for invalid or empty fields
* Completed confirmation state
* Reset form after confirmation
* Hover and focus states for interactive elements

## Built With

* React
* TypeScript
* Tailwind CSS
* Vite

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jzzmiiinn/Interactive-card-details-form.git
```

### 2. Navigate to the project

```bash
cd Interactive-card-details-form
```

### 3. Install dependencies

```bash
pnpm install
```

### 4. Start the development server

```bash
pnpm dev
```

Open the local URL provided by Vite in your browser.

## Challenge

This project was built as part of the **Frontend Mentor Interactive Card Details Form** challenge.

The challenge focuses on creating a responsive form where users can enter card information, see the card update in real time, receive validation errors, and view a completed state after successful submission.
